# 好友德州 · Hold'em

一个跑在自己电脑上的联机德州扑克网页游戏。启动服务、创建房间，把局域网链接发给同一 Wi-Fi 下的朋友，就能开桌。

只使用虚拟筹码，仅供朋友间娱乐。

## 功能

- 2–9 人无限注现金桌，盲注可选 `5/10`、`10/20`、`25/50`、`50/100`，买入 100BB
- **人机对战**：可选择 1–8 位 AI 对手，随时一个人开局；AI 会估算胜率并自动行动
- 完整规则：盲注与按钮轮转、最小加注、短码 all-in 不重开加注、多路 all-in 边池、平局分池与奇数筹码
- 服务端权威结算：底牌只发给本人，前端拿不到别人的手牌；AI 也只使用公开信息做决策
- 30 秒行动倒计时，超时自动过牌 / 弃牌
- 刷新页面或短暂断线后自动回到原座位，筹码不丢
- 牌桌筹码可视化：下注与底池按面值显示成小筹码堆（5 红、10 蓝、25 绿、100 黑），精确金额仍显示在文字里
- 9 位原创角色头像，每位玩家（包括 AI）入座时随机分配，同桌不重复
- Web Audio 合成音效：发牌、翻牌、弃牌、过牌、跟注、加注、全下、轮到你、摊牌与获胜，可一键静音并记住设置
- 房间内聊天、牌局记录、摊牌亮牌、胜者结算展示
- 手机 / 平板自适应

## 快速开始

### Windows 一键启动

1. 安装 [Node.js](https://nodejs.org/) 20 LTS 或更高版本
2. 双击项目目录里的 **`启动游戏.bat`**
3. 浏览器会自动打开 `http://localhost:3000`
4. 输入昵称，选择盲注。想和朋友玩就点「创建房间」；想自己练手就点「人机对战」，选 1–8 位 AI
5. 点右上角「邀请」，复制局域网链接发给朋友

朋友需要和你连同一个 Wi-Fi，打开链接、输入昵称即可入座。**满 2 人后自动开局。**

人机房间同样可以邀请朋友：AI 占据一部分座位，朋友会坐到剩余空位，和 AI 同桌。房主离开后，如果房间里没有其他真人，房间会关闭。

### 手动启动

```bash
npm install        # 首次运行安装依赖
npm run play       # 构建前端并启动服务（默认端口 3000）
```

启动后终端会打印：

```
本机访问   http://localhost:3000
局域网访问 http://192.168.x.x:3000
```

关闭终端窗口即停止服务。

## 朋友连不上？

- 确认双方在**同一个 Wi-Fi / 局域网**
- 首次启动时 Windows 防火墙弹窗请选择「允许访问」，并勾选「专用网络」
- 公共 Wi-Fi 经常开启 AP 隔离，设备之间无法互访；建议用手机热点或自己的路由器
- 电脑有 VPN、虚拟机网卡时，请确认使用分享弹窗里显示的 Wi-Fi 地址；分享链接会自动过滤常见虚拟网卡
- 若要换端口：Windows CMD 里执行 `set PORT=8080 && npm run play`，然后访问 `http://localhost:8080`

## 玩法说明

- 创建房间后自动入座；第 2 人入座约 2.5 秒后自动开第一手，之后每手结束展示 6.5 秒自动继续
- 人机模式里 AI 会在约 0.4–0.9 秒内行动；筹码输光的 AI 会在下一手开始前自动重新买入
- 牌局进行中不能离开房间，避免带走底池；本手结束后再离开
- 真人筹码输光后，在本手结束（或本手旁观时）可点「重新买入」，恢复到 100BB
- 房间数据保存在内存中，重启服务会清空所有房间与筹码
- 同一浏览器刷新页面会自动恢复座位；换浏览器或清理缓存则视为新玩家

## 角色

牌桌最多 9 个座位，对应 9 位原创角色。每位玩家（包括 AI）入座时会从还没被占用的角色里随机拿一个，同一张牌桌不会出现重复角色；离座后角色释放，刷新或断线重连会保留原来的角色。

头像资源在 `public/characters/`，随机分配逻辑在 `server/src/game/table.ts`。

## 音效

- 默认开启，点击房间右上角的喇叭图标可以静音，设置会保存在浏览器里
- 发牌、翻牌、弃牌、过牌、跟注、加注、全下、轮到你行动、摊牌和获胜都有独立音效
- 全部用 Web Audio 在浏览器里实时合成，不依赖外部音频文件
- 受浏览器自动播放策略限制，页面需要先有一次点击或按键才会出声

## 开发

```bash
npm run dev        # 开发模式：前端 5173，后端 3000（Vite 已代理 Socket.IO）
npm test           # 牌型评估、牌局规则、随机对局与 AI 对局压力测试
npm run typecheck  # TypeScript 全量检查
npm run build      # 构建前端到 dist/
npm start          # 直接启动服务（需先构建）
```

> 开发模式和生产服务都会占用 3000 端口，不要同时运行。先关闭正在运行的服务，再 `npm run dev`。

## 项目结构

```
server/src/game/evaluator.ts   牌型评估（7 选 5，支持 A-5 顺子）
server/src/game/bot.ts         AI 决策：翻前牌力 + 翻后蒙特卡洛胜率
server/src/game/table.ts       牌局状态机（下注轮、all-in、边池、摊牌分池、AI 行动调度、角色分配）
server/src/rooms.ts            房间、会话、断线重连、房间回收
server/src/index.ts            Express + Socket.IO + 局域网地址
shared/protocol.ts             前后端共享类型与常量
public/characters/             9 位角色头像
src/sound.ts                   Web Audio 合成音效引擎
src/useGameSounds.ts           牌局事件到音效的映射
src/                           React 前端（主页、牌桌、操作栏、聊天）
```

## 以后部署到公网

服务是单进程：Express 托管构建后的静态页面，Socket.IO 提供实时通信，同一个端口即可工作。放到任意支持 Node.js + WebSocket 的云主机，构建后 `npm start` 即可。

- 公网请使用 HTTPS / WSS（Caddy、Nginx 反向代理或平台自带域名）
- 房间与筹码都在内存里，服务重启会清空
- 没有账号系统，拿到房间号的人都能加入，请勿直接当作公开大厅使用

## 声明

- 本项目仅用于朋友间娱乐，筹码为虚拟数值，不涉及任何真实货币、支付或抽水
- 请勿用于任何形式的赌博
